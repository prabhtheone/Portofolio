## ⚙️ Running Locally

This is a lightweight static website.

1. Clone the repository:

```bash
git clone https://github.com/prabhtheone/Portofolio.git
cd Portofolio
```

2. Open `index.html` directly in a browser, or serve the directory with any static HTTP server.

3. For the Supabase-powered project list, configure the Supabase URL and publishable/anon key in `config.js`.

> Never put a Supabase service-role key or other private credentials in the frontend.

## ☁️ Deployment

The website is deployed using **Vercel** and is connected to the GitHub repository. Updates pushed to the main branch can be deployed automatically.
